# 중국 기준 구현 및 검증

적용일: 2026-10-15. 헤더의 설계기준에서 중국(CN)을 선택한다. UI 언어 선택과 설계기준 선택은 독립적이다.

## 사용 흐름

공장 생성 → 입력 카드 수정·실행 → 해석 → 설계 검토 → 단면 최적화 → 계산서·DXF.
국가를 변경하면 이전 입력 카드는 실행할 수 없고 새 국가의 기본값으로 시작한다. 이미 생성한 모델의 검토·출력은 그 모델에 저장된 국가를 따른다.

## Gen 연동

- 재료: `GB03(S)`의 Q235/Q345. 모델상 재료명은 Q235B/Q345B, 퍼린·거트는 별도 Q235B.
- H형강·강관: `GB-YB05`. C형강: `GB50018-02`(DB 이름이며 검토 규범의 판본을 뜻하지 않는다).
- 공개 설계 API 문서의 중국 코드는 GB50017-03이다. 2017 설계라고 표시하며 구판 DSTL을 보내지 않도록 CN에서는 DSTL을 생략한다. 부재·접합 검토는 앱의 별도 GB 계산이다.
- 기본 형상: 24×36 m, 처마 8 m. 절점 219, 요소 410, 하중 13, 조합 51. 적설 0 또는 지붕 경사에 따라 케이스·조합 수가 달라진다.
- CN 벽 가새는 온도구획 중앙, 지붕 가새는 양 끝 및 벽 가새 위치에 배치한다. 가새 교차점의 중간지지는 인정하지 않는다. TW 가새 위치는 유지한다.
- 중국 부재력 표는 4개 조합씩 나눠 회수한다. 누락된 부재력·사용성 변위는 오류로 처리한다.

## 적용 범위와 계산 가정

현재는 규칙적인 단층·단일 스팬·폐쇄형 금속 외장 공장용이다. 처마 ≤18 m, 스팬 ≤60 m, 평균 지붕 높이 ≤20 m, 길이 ≤90 m, 경사 ≤1, 감쇠비 0.045–0.05 범위를 검증한다. 큰 개구부, 다층, 크레인, 다중 스팬, 온도하중·피로·화재는 포함하지 않는다. 8/9도 수준(`αmax≥0.16`)이고 스팬 >24 m인 경우 수직지진 모델이 필요하므로 현재 입력을 거부한다.

지역별 풍압·적설·지진 지도는 자동 조회하지 않는다. `w0`, 지표조도, 지형계수, `αmax`, `Tg`, `Tx/Ty`, 적설, 중요도 및 기초 재료값을 프로젝트 조건으로 입력해야 한다. 기본값은 예시다. 지붕 활하중은 풍·적설과 동시 조합하지 않는다. 지진 중량은 D+0.5S, 지진 조합 계수는 GB 55002의 G=1.3/Eh=1.4를 사용한다.

- Gen 선형 해석 결과에 부재 및 층 안정 증폭을 적용한다. 고유치 해석·비선형 해석에 의한 주기나 2차 효과를 자동 산정한 것으로 보지 않는다.
- 주각 고정/핀 및 보-기둥 강접 가정으로 K를 계산한다. 접합부의 실제 회전강성은 별도 확인 대상이다.
- 탄성 단면계수, 모멘트 분포계수 1을 사용한다. H형강 판 세장비 초과 시 후좌굴 강도를 인정하지 않고 NG 처리한다.
- C형강 유효폭은 인접 판의 유리한 구속효과를 인정하지 않는 보수적 단면 감소 근사다. 비틀림·휨비틀림 검토도 단면 근사를 포함한다. 외장재의 횡지지를 자동 인정하지 않는다. 새그로드는 입력 개수의 양방향 지지 효과를 가정하므로 실제 상세가 이를 제공해야 한다.
- 국부 풍압은 부재가 걸친 가장 불리한 구역을 전 길이에 적용하며 면적 저감은 인정하지 않는다. C형강으로 통과할 후보가 없으면 압연 H형강도 보조 부재 후보에 포함한다.
- 풍 횡변위 H/150은 보수적 선택이다. 지진 H/250은 다층 표를 참고한 프로젝트 관리 기준이며 단층 공장 전체에 자동 적용되는 규정값이라고 표시하지 않는다. 금속 지붕 보 L/180, 퍼린 L/150을 적용한다.
- 접합부는 자동 예비 치수 산정이다. 10.9 마찰접합, 표준 구멍, 마찰계수 0.40, 접촉면 1개를 가정한다. 주각 앵커는 인장만 담당하고 전단은 마찰+전단키로 전달한다. 재료표 검증 두께는 최대 100 mm이며 그 이상이 필요하면 통과시키지 않는다.
- 콘크리트 파괴·앵커 정착·전단키 정착, 접합부 강성·회전능력·볼트 실제 배치, 가새 거셋 좌굴·강관 순단면·블록전단·용접 상세는 별도 상세 검토가 필요하다. 화면 및 계산서에도 표시한다. 처마 1.2Mp·가새 1.1FyAg는 프로젝트 접합부 용량 포락 가정이다.

따라서 검토의 OK는 구현된 계산 항목의 통과를 뜻한다. 중국 규범의 모든 구조·내진 상세를 포함한 최종 승인이나 접합 상세 완성을 뜻하지 않는다.

## 재현 검증

```sh
node --import tsx scripts/verify-cn.ts
npm run typecheck
npm run build
node --import tsx scripts/live-cn.ts --optimize
```

라이브 스크립트는 키를 표준입력으로 받고 메모리에만 유지한다. 기존 Gen 문서를 자동 저장한 뒤 새 모델을 만들므로 시험용 Gen 세션에서 실행한다. 보고서 HTML·DXF·검토 JSON은 OS 임시 폴더의 `smart-midas-cn-live.*`에 생성한다. `--reuse`는 Gen에 현재 기본 사양과 일치하는 해석 모델이 있을 때만 사용한다.

오프라인 검증은 원문 표의 재료강도·좌굴계수·풍압·스펙트럼 앵커, 순단면적, 순수 휨 LTB, 적설 경사·편적설, 하중 합, 국가별 가새 위치·DB 매핑, 적용 범위 차단 및 TW 하중 15/조합 55 유지를 확인한다.

| DXF R12 감사 | 요소 623개, 오류·수정 0 |

초기 C형강 샘플은 국부 풍압/LTB, 작은 가새는 세장비·안정 검토에서 NG였다. 중국 단면 후보로 재전송·재해석한 결과 3회에 부재 NG 0에 도달했다(45.30→57.34 t). 이는 초기 NG를 해소하면서 중량이 증가한 사례이며 경량화 성과로 표시하지 않는다. 접합부는 순단면 및 보강판 두께에 따른 설계강도를 적용한 뒤 위 기본 샘플에서 모두 1.0 이하를 확인했다.

이 기본 샘플에서 최종 코드로 전체 흐름을 다시 실행했다(`--optimize --assert-pass`, 종료 코드 0). 2회 검토·재해석으로 기둥/지붕보가 HN 500x200x10/16으로 변경되어 **57.34→52.62 t, 약 8.2% 감소**했다. 최종 부재·사용성 NG 0, 부재 최대비 0.9201, 사용성 최대비 0.5353, 접합비 주각 0.9454/처마 0.9217/마루 0.9396/가새 0.9856, API 오류 0이었다. HTML 10장과 DXF를 생성했다. Gen에는 이 최종 해석 모델을 남겼으며 시험 전 문서는 자동 저장했다.
