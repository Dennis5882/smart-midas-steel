# 한국 기준(KR, KDS) 구현 — 1단계

적용일: 2026-10-16. 프로젝트 설정의 설계기준에서 `KDS 41 30 10 · KDS 14 31`을 고른다. 한국어 화면의 새 작업은 KR로 시작한다(강제 아님). 간체(zh-CN)에서는 CN만 선택할 수 있다는 기존 규칙은 그대로다.

## 사용자 결정 (2026-10-16)

- 부재·접합 검토는 TW·CN과 같이 **앱 자체 계산**으로 한다. Gen NX의 KDS 강재 설계 결과는 라이브 스크립트에서 **대조용**으로만 쓴다.
- 1단계: 전체 흐름을 구현한다. 하중·조합·부재·사용성·Gen 연동·계산서·DXF·최적화가 대상이다.
- 2단계: 접합부(KDS 14 31 25), 외장재 풍하중(5.4·5.8), 냉간성형 C형강(KDS 41 30 30), 내진상세(KDS 14 31 60).

## Gen 연동 (라이브 확인 2026-10-16)

연동명은 `wg_api_framework.dll` 문자열에서 찾았고, 라이브에서 모두 수용됐다(박공·편경사·다경간, API 오류 0).

라이브에서 발견해 고친 것:
- 가새(TRUSS)에는 보 하중을 넣을 수 없다("Beam Loads cannot be entered"). 가새 가상하중은 양 끝 절점에 반씩 절점하중으로 보낸다.
- 한 절점에 같은 하중 케이스 항목이 둘 이상이면 Gen은 하나만 남긴다. 같은 케이스는 합산해서 보낸다(회귀 검사 포함).
- 하중조합 이름은 20자 이하. 조합 이름에서 `KDS ` 접두사를 뺐다(최대 17자).
- Gen KDS 설계: DSTL 지정 뒤에는 재해석이 필요하고, 강재 설계용 조합 `db/LCOM-STEEL`(STRENGTH)이 없으면 `CODE-ANAL`이 `failed:LoadCombination`을 낸다.

- 재료: `STANDARD 'KS22(S)'`, DB = 강종명(SS275, SM355 …). 퍼린·거트는 MATL 2(SS275)로 보낸다.
- 단면 DB `KS21`: `H 600x200x11/17`, `LH 150x75x3.2/4.5`, `P 139.8x4.5`. LH의 SHAPE는 `H`로 가정했다.
- 강재 설계 코드는 구 `db/DSTL`이 아니라 `DESIGN/STEEL/DSTL`(`KDS 41 30 : 2022`, MIDAS API 매뉴얼 25장)이다. 모델 생성 때는 보내지 않고, 라이브 대조 `--gen-check`에서만 설정한 뒤 `CODE-ANAL`(60 s 제한) → `post/STEELCODECHECK`.
- 가상하중 케이스(NXD…)의 STLD TYPE은 `USER`다.
- KS21에는 립 C형강이 없다. 1단계 퍼린·거트는 LH 또는 압연 H이고, KDS 14 31 10으로 모두 검토한다.

## 계산 가정 (계산서 10장에도 표시)

**지진구역계수**
- Z(I 0.11 / II 0.07)는 KDS 17 10 00 통상값이다. KB에 이 기준이 없다.
- S = Z × 2.0이며 입력에서 고칠 수 있다.
- 기본풍속 V0와 지상설하중 S_g는 지도 값을 입력한다. 샘플은 서울 예시값이다.

**풍**
- G_D는 강체(n_D > 1 Hz)만 다룬다. 근사주기 Ta ≥ 1 s이면 막는다.
- G_pe의 지붕보 고유진동수는 단순보 근사다. 실제 골조보다 진동수가 낮으므로 보수적이다.
- 다경간(θ ≥ 10°)은 표 5.7-1에 다경간 지붕 표가 없다.
  - 첫 풍상면에는 풍상 표를, 나머지 면에는 풍하 표를 적용한다.
  - 이 때문에 경고 `multiKR`을 낸다.
- 불균형 적설 4.5.3에서 처마 쪽 면은 0.5S_f로 가정했다.

**설하중 최소값**
- 4.3.5(2)를 문자 그대로 적용한다.
- θ ≤ 15°이고 S_g ≤ 1.0이면 최소 설하중은 max(I_s·S_g, 1.0)이다.
- 그래서 서울 샘플의 설하중은 1.0 kN/m²이다.

**조합 축소**
- 대칭 골조에서 거울상 조합은 생략한다(좌우·길이 대칭일 때만).
- 지진 조합의 적설은 균형 적설만 쓴다.
- 1.7-2는 1.7-3에 포함되므로 생략한다.

**사용성 — 프로젝트 기준**
- KDS에는 수치 한계가 없다.
- 지붕보·퍼린: L/240 (L_r 또는 S).
- 풍 횡변위: H/150 (0.65W, 재현기간 50년).

**강도**
- 인장은 총단면 항복만 검토한다. 유효순단면 파단은 2단계 접합부 검토에서 다룬다.
- 웨브가 세장한 H는 미구현이며 NG로 처리한다. 후보 단면에는 해당 단면이 없다.
- B2 > 1.5이면 유효길이법 조건 밖이므로 골조 부재 주석에 표시한다.

**적용범위 경고 `krPhase`**
- 항상 표시하므로 전체 등급은 「전문가 검토 필요」다.
