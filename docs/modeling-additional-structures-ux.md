# 모델링 7단계와 추가 구조 입력

2026-10-18 · v2.3.2

## 화면 구성

1. 시작: 건물 템플릿만 선택한다.
2. 횡단면: 단경간 박공·편경사·다경간과 기둥 베이스를 설정한다.
3. 길이·베이: 등간격/개별 간격과 보조부재 간격을 설정한다.
4. 재료·단면: 국가·재료별 카탈로그 단면을 선택한다.
5. 추가 구조: 크레인, 메자닌·플랫폼, 개구부, 건물 연결부, 기존 지붕 설비 기능을 항목별 카드에서 설정한다.
6. 지역·하중: 공통 고정하중·풍·지진·적설을 설정하고 추가 구조의 개별 하중은 요약으로 확인한다.
7. 최종 확인: 형상·재료·추가 구조 요약과 적용범위를 확인하고 Gen 모델을 생성한다.

초기 적용범위 체크박스는 제거했다. `ScopeBox`는 판정만 표시한다. 다경간은 횡단면 형식이며 건물 연결부와 별개다. 기존 `features.multiSpan` 값은 유지하되 사용자가 횡단면을 명시적으로 바꾸면 해당 형식과 동기화한다.

## 추가 구조 카드

- 카드 요약을 펼치면 해당 항목을 활성화하고 바로 상세 입력할 수 있다.
- 상태는 없음 / 입력 필요 / 입력 확인으로 표시한다. 입력 확인은 강도 합격을 뜻하지 않는다.
- 크레인과 플랫폼은 각각 활성화한다. 개구부 카드에서는 닫힌 측벽 출입문·닫힌 지붕 개구부·플랫폼 바닥 개구부를 따로 설정한다.
- 바닥 개구부는 플랫폼이 있을 때 설정한다. 비활성 플랫폼에 남아 있는 바닥 개구부를 활성으로 표시하지 않는다.
- 연결부의 분리·미끄럼·일체형 제한과 기존 외부 반력 인터페이스를 유지한다. 연결 건물 전체 형상을 자동 생성하지 않는다.
- 지붕 설비 추가·삭제와 하중 조합계수/출처 확인도 이 단계에 모았다.
- `AdditionEditor.part`와 `Phase6Editor.part`로 기존 입력을 분리해 표시한다. 확인·오류·모델 데이터는 동일한 `FactorySpec`에 저장한다.

지역·하중 및 최종 확인의 `StructureSummary`는 입력창을 복제하지 않는다. 개별 하중·단면·활성 항목을 요약하고 수정 버튼으로 추가 구조 단계에 돌아간다.

## 검증·이동

- `modelingFlow.ts`가 7개 단계와 추가 구조 오류 그룹을 정의한다.
- `fieldStep`: 형상 1, 베이 2, 재료 3, 추가 구조 4, 공통 하중 5 (0부터 시작).
- 아직 도달하지 않은 단계의 미완료 입력으로 이전 단계에 갇히지 않는다. 다음 단계로 갈 때 가장 앞선 미완료 단계로 안내한다.
- 추가 구조 오류는 해당 카드를 펼치고 입력 영역에 포커스를 이동한다. 미입력 안내가 지역·하중으로 보내지 않도록 4개 언어 문구도 수정했다.
- 형상·간격·재료·단면 변경과 등간격/개별 간격 전환 시 추가 구조의 출처 확인을 해제한다. 공통 지역·하중 변경은 별도 입력값의 확인 상태를 유지하며 해석 결과의 기존 변경 감지는 계속 적용한다.
- 지원 범위·국가별 하중·출처 확인·생성 차단 규칙은 최종 생성에서도 적용한다.

- 공통 오프라인 검증 26종 통과. 이후 바뀐 안내 문구는 PDF·글꼴 검증과 전용 흐름 검증으로 재확인한다.
- 브라우저: 초기 체크박스 제거, 추가 구조 없이 다음 단계 진행, 측벽 출입문 설정→공통 풍하중 변경→입력 확인 유지, 형상 변경→추가 구조 재확인, 미입력 크레인 진행 차단을 확인했다.
- 이번 UX 변경의 검증에서는 Gen 문서를 바꾸지 않았다. 직전 Gen 성질 전환의 라이브 결과는 별도 기록이다.
