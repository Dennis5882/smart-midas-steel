# 台灣結構技師審閱問卷 — Smart MIDAS Steel 廠房精靈

> 對象：台灣執業結構技師 2~3 位　｜　預計作答時間：約 30 分鐘
> 網址：https://steel.midasapi.space/zh-TW/　（不需連線 MIDAS Gen 也可操作精靈與 3D 預覽）
> 作答方式：在每題「回覆」欄填寫；同意現行寫法請填「OK」。

本工具依使用者輸入自動建立單層鋼構廠房（門式剛架）MIDAS Gen NX 模型，並依台灣規範進行荷載、分析後之構材與接合檢核。以下問題用來確認**用語**、**提問順序**與**實務習慣**是否符合台灣設計現場。

## B. 提問順序（精靈步驟）

目前步驟：

1. 開始與範圍（建築用途範本、是否有天車／夾層／大開口）
2. 橫斷面（剛架形式、跨距、簷高、屋頂坡度）
3. 長度與開間（開間數、柱距，可逐跨輸入）
4. 材料與斷面
5. 地區與荷載（縣市→鄉鎮自動帶入 V10、S<sub>S</sub>/S<sub>1</sub>、近斷層距離、地盤種類、屋頂/牆面附加靜載重）
6. 最終確認 → 建立模型

|---|---|---|
