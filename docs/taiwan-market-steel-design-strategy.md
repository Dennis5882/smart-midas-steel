# 대만 시장 강구조 공장 설계: 조사와 제품 개선 방향

작성일: 2026-10-19 · 상태: 조사·제안, 구현 승인 및 완료 기록 아님

## 1. 목적과 결론

대만 공장 설계 실무에서 요구하는 설계 근거 체계(법규·규범·판본)와 현재 앱의 반영 상태를 대조해 대만판 개선 방향을 정리한다. 출발점은 대만 측에서 받은 아래 요구 정리다.

> - 基本法規：依據建築技術規則建築構造編及鋼構造建築物鋼結構設計技術規範。
> - 設計方法：可採用容許應力設計法（ASD）或極限設計法（LRFD）（參照最新美制 AISC 精神整合規範）。
> - 輕型／冷軋型鋼門架：若使用冷彎薄壁型鋼（C型、Z型鋼等），應另參照冷軋型鋼構造建築物結構設計規範及解說。
> - 銲接標準：結構接合與銲道需符合 AWS D1.1（一般鋼結構銲接規範）或 AWS D1.8（耐震補充規定）。

우선 대상은 **MIDAS Gen NX를 사용하는 대만 구조기사(結構技師)·설계팀이 정형·등단면 강구조 공장의 모델링, 하중, 해석, LRFD 검토와 簽證용 계산서를 빠르게 준비하는 업무**로 제안한다.

대만판 핵심 개선 방향:

1. **규범 판본 관리** — 현행 강구조 규범(2007 제정, 2010 일부 수정)과 개정 연구 중인 통합판(AISC 360-16 기반)을 구분하고 판본을 계산서에 명시한다.
2. **ASD(容許應力／容許強度) 설계법 추가** — 현재는 LRFD만 지원한다.
3. **工址 지진 입력 보완** — 근단층(鄰近斷層) 鄉鎮의 표 2-3 계수를 경고에 그치지 않고 입력 흐름에 연결한다.
4. **냉간형강 적용 범위 확대** — 남은 검토 항목을 보완하고 Z형강 퍼린 수요를 확인한다.
5. **용접·접합 근거 명시** — AWS D1.1/D1.8 적용 범위와 내진 접합의 시험 근거(13장)를 계산서·도면의 확인 항목으로 만든다.
6. **簽證 계산서 정합** — 건축 허가(建照) 심사·抽查 항목 순서와 용어에 맞춘 번체 계산서를 제공한다.

공통 기능의 전체 우선순위는 [개선 로드맵](roadmap.md)에서 관리한다. 이 문서의 제안 순서는 프로젝트 저장·복원, 계산 대조 등 공통 과제의 우선순위를 대체하지 않는다. 중국판 제안은 [중국 시장 문서](china-market-steel-design-strategy.md)를 참고한다.

## 2. 조사 범위와 해석상의 한계

- 규범 판본은 내정부(內政部) 공보·건축연구소(建築研究所) 연구 보고서·건축사 공회 공지 등 공개 자료와, 보유 원문 KB(`E:/MIDAS PROGRAM/COde/TW/knowledge`)의 판본 기록으로 확인했다.
- 내정부 법규 시스템(glrs.moi.gov.tw)의 연혁 페이지는 조사 시점에 접속되지 않았다. 판본 관련 서술은 검색 결과 요약과 공보 자료에 근거하므로 착수 전 공식 연혁으로 다시 확인한다.
- 대만 경쟁·대체 도구(ETABS·SAP2000 후처리, 강구조 업체 자체 계산 등)는 공개 자료가 적어 기능 비교를 하지 않았다. 설치 비교 시험도 수행하지 않았다.
- 시장 규모, 냉간형강·Z형강 사용 비율, ASD 수요 비율은 이번 자료만으로 판단하지 않는다.
- 아래 화면·순서는 제품 제안이다. 구조 계산 규칙의 확정이나 현행 규범 적합성 인증을 의미하지 않는다.

## 5. 우선 고객과 적용 범위

### 5.1 우선 고객 가설

- Gen NX를 쓰는 대만 구조기사 사무소·설계팀(簽證 책임자).
- 강구조 제작·시공 업체의 설계 부서(정형 공장을 반복 설계, 단면·물량 비교).
- 크레인이 있는 일반 공장을 설계하며 계산서와 Gen 모델을 함께 인계해야 하는 사용자.

제품 가치는 **반복 입력 감소, 규범 판본이 드러나는 계산 근거, Gen 모델과 웹 검토 결과의 연결**로 제안한다. 실제 효용은 대만 현지 사용자 작업 시험으로 확인한다.

### 5.2 범위를 명확히 해야 하는 프로젝트

용접 변단면, 복수 크레인, 큰 개구부(부분 밀폐), 높이 12 m 초과(표1-3 R 조건), 근단층 공지, 비정형 배치, 상세 제작도 중심 업무는 별도 요구사항과 검증이 필요하다. 모델 일부를 만들 수 있어도 해당 프로젝트 전체 설계를 완료했다고 표시하지 않는다.

번체 안내 문안 초안:

> 適用於規則、等斷面鋼構造廠房之參數化建模與設計檢核，聯動 MIDAS Gen NX 完成結構分析。

화면에서는 각 기능을 **自動處理 / 需補充輸入 / 需專案設計**로 구분하고, 최종 결과에도 미검토 항목을 유지한다.

## 6. 개선 방향

### 6.1 규범 판본 관리 (TW-M01)

- 프로필에 **규범 판본 식별자**(예: 강구조 2010권 LRFD, 내진 113년판, 내풍 2014판, 냉간 104년판)를 두고 상태 카드·계산서 머리·`kv_code`에 표시한다.
- 통합 개정판이 공식 시행되면 기존 판본과 **병행 선택**할 수 있게 한다(경과 기간 중 두 판본 프로젝트 공존). 식이 바뀌는 조항(14장 내진 예상강도, 조합·저항계수)은 별도 프로필 파일로 격리한다.
- 원문 KB 판본이 불명확한 강구조 규범은 공식 PDF로 대조해 판본을 확정한다. 확정 전에는 계산서에 '판본 확인 중'을 표시한다.

### 6.2 ASD(容許應力／容許強度) 설계법 (TW-M02)

- 같은 Gen 해석 결과에 ASD 하중조합과 허용응력(또는 개정판의 容許強度 = R_n/Ω)을 적용하는 별도 검토 경로를 만든다. 프로필 `method`에 'ASD' 값이 이미 정의돼 있다.
- 범위: 부재(인장·압축·휨·조합), 사용성, 접합(볼트·용접·주각), 최적화 목표비. LRFD와 같은 회귀 체계(손계산 + 정답 세트)를 만든다.
- 화면에서 설계법을 프로젝트 시작 시 선택하고, 결과·계산서·물량에 설계법을 함께 기록한다. 설계법을 섞은 결과를 하나로 비교하지 않는다.
- 착수 전 확인: 현지 실무의 ASD 사용 비율, 그리고 통합판에서 ASD가 '容許強度設計法'으로 바뀌는지 여부(구현 대상 식이 달라짐).

### 6.3 工址 지진 입력 보완 (TW-M03)

- 鄰近斷層 鄉鎮을 선택하면 표 2-3-1~2-3-4의 근단층 구역 계수를 입력 흐름에 표시하고 단층 거리(구간) 선택으로 S_S^D·S_1^D·S_S^M·S_1^M을 확정한다.
- 현재의 '표값/사용자 입력/표에 없음' 출처 표시(`siteSource`)를 근단층 값에도 적용한다.
- 用途係數 I, 지반 분류, 대북분지 미세구역은 기존 입력을 유지하되 근거 자료(지반조사 보고서 등)를 기록할 칸을 둔다.

### 6.4 냉간형강 적용 범위 (TW-M04)

- 남은 항목(약축 유효폭, 편심 비틀림, 웨브 국부지압, 클리트·새그로드 접합)을 冷軋型鋼 규범 원문과 대조해 구현하고 예비검토 범위를 줄인다.
- Z형강 퍼린: 실무 수요를 확인한 뒤 CNS 단면 카탈로그(Gen DB 수용 여부 라이브 확인)와 검토식(비대칭 단면의 주축 휨·연속보 겹침)을 추가한다.
- 로드맵 R06(냉간성형·횡지지·접합 상세)과 통합해 진행한다.

### 6.5 용접·접합 근거 (TW-M05)

- 1차는 **명시 중심**: 계산서와 DXF 접합 일람에 용접 규격(AWS D1.1, 내진 접합은 D1.8), 용접 종류(CJP·필릿)와 크기, 'Demand Critical 용접 여부·인성 요구는 설계자 확인' 항목을 넣는다.
- 처마 모멘트 접합은 13.6.1 회전능력 시험 근거가 필요하다는 현재 등급 표시를 유지한다. 이와 함께 **사전 인정 접합 형식이나 기존 시험 근거를 입력해 확인 상태로 바꾸는 경로**를 검토한다(근거 문서 기록 필수, 자동 통과 아님).
- 용접 상세 설계(이음 형상·예열 온도 산정)는 범위 밖으로 둔다.

### 6.6 簽證 계산서 정합 (TW-M06)

- 건축 허가 심사표의 항목(靜載重·活載重·地震力·風力·材料規格·平面/豎向/基礎配置)을 계산서 장 구성과 대응시켜 심사자가 찾기 쉽게 한다. 생략 항목은 사유를 쓰는 칸을 둔다.
- 번체 용어는 대만 규범 용어(屋樑·檁條·牆樑·工址·鄉鎮)로 통일하고, 표·수식의 조항 번호를 규범 판본과 함께 표기한다.
- Word 계산서는 회사·사무소 양식(.dotx) 적용을 지원한다(양식 파일 수령 후, 공통 과제).

### 6.7 크레인 공장

대만 일반 공장은 천장 크레인 수요가 높다. 현재의 크레인 구간·차륜 하중·주행보 예비검토를 기반으로, 로드맵 R05(크레인 검증·하중 조합 확대)에서 풍·지진 + 크레인 동시 조합과 13장 연동(크레인 지지 기둥의 내진 요구)을 함께 다룬다. 크레인을 받는 기둥은 흔들림 기둥으로 만들지 않는 기존 규칙을 유지한다.

### 현지 사용자 작업 시험 제안

대만 실무자에게 익명화된 프로젝트 조건(공지 주소·지반 분류·크레인 자료)을 제공하고 다음을 관찰한다.

1. 모델 생성부터 해석·검토·계산서까지 걸리는 시간과 도움 요청 횟수.
2. 鄉鎮·지반·用途係數 입력과 근단층 판단의 오입력·수정 과정.
3. 계산서를 簽證·심사 제출용으로 그대로 쓸 수 있는지, 추가로 요구하는 항목.
4. ASD를 요구하는지, LRFD만으로 충분한지.
5. 냉간 C·Z형강, 용접 변단면, 크레인 규모 등 실제 프로젝트의 범위.

시험 전부터 생산성 향상률이나 시장 적합성을 확정하지 않는다.
