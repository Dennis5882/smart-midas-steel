# Gen 하중 읽어 오기(엔지니어 하중) — 인식 범위와 해석 후 동작

> 상태: **계획(미구현)**, 2026-10-21 정리. 선행 기능 「모델 + 자중만」 전송은 구현됨(7단계 `GenContentPicker`, `Built.modelOnly`).
> 배경: 대만 회의(`docs/taiwan-meeting-2026-10-20.md` F2) — 자동 하중을 바로 믿기보다 엔지니어가 Gen 에서 하중을 넣고 앱이 읽어 와 검토하는 흐름 요청.

## 흐름

1. 앱 → Gen: 「모델 + 자중만」 생성
2. 엔지니어: Gen 에서 하중 케이스·하중·조합 입력
3. 앱: **Gen 불러오기** — 형상 동일성 확인 + 하중·조합 읽기
4. 앱: **불러온 내용 확인(해석 전)** — 모델 차이, 케이스별 하중 형식·합력, 조합 표, 누락 경고, (선택) 앱 자동 하중과 비교
5. 사용자 확인 체크 → 해석(`doc/anal`, 자동 저장 선행)
6. 반력으로 케이스별 하중 합계 확정
7. 설계 검토 → 산출물

## 3. 단계 계획

- **1단계**: 불러오기(형상 동일성 + 하중·조합 읽기) → 확인 화면 → 해석 → 반력 확정 → 부재·접합·사용성(케이스 종류 기준). 내진 특수·ASD 는 전문가 검토. 형상이 바뀌었으면 막음.
- **2단계**: 조합 용도 지정 화면(증폭 지진·중력·ASD, 이름 규칙 자동 추정 + 수정) → 내진 특수 검토 개방, 단면 변경 받아들이기, 최적화·NG 보완을 '단면만 바꾸기' 방식으로.
- 보류: 부재 추가·삭제 모델 받아들이기, 3D 하중 화살표 표시.

## 4. 기술 메모

- 형상 동일성은 기존 `assertGenSync`(13 DB) 에서 하중 DB(`STLD`·`BODF`·`BMLD`·`CNLD`·`LCOM-GEN`)를 빼고 형상 DB 만 비교.
- `LoadInfo` 에 의존하는 설계 코드(`comboKind`·`wind.variants`·`seismic`·`omega`) 는 엔지니어 하중일 때 대체값 필요 — 모든 조합 `basic`, 풍 변형·지진 계수 없음 → 해당 검토는 전문가 검토 이슈.
- 결과 지문·재사용(`reusableResults`) 은 그대로 사용 가능.
- 계산서 PDF 글꼴 축소본에 새 문구 글자 확인(verify-pdf).
