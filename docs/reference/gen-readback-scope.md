# Gen 하중 읽어 오기(엔지니어 하중) — 인식 범위와 해석 후 동작

> 상태: **1단계 구현(2026-10-26, TW·추가 구조 없음)** — 해석 단계 화면 `GenReadPanel`([Gen 하중 불러오기] → 해석 전 확인 → 확정), `domain/genLoads.ts`(요약·하중 정보)·`actions/readback.ts`. 2단계(조합 용도 지정·단면만 바꾸는 최적화/NG 보완)는 미구현. 선행 기능 「모델 + 자중만」 전송은 생성 확인 창에서 선택.
> 배경: 대만 회의(`docs/taiwan-meeting-2026-10-20.md` F2) — 자동 하중을 바로 믿기보다 엔지니어가 Gen 에서 하중을 넣고 앱이 읽어 와 검토하는 흐름 요청.

## 흐름

1. 앱 → Gen: 「모델 + 자중만」 생성
2. 엔지니어: Gen 에서 하중 케이스·하중·조합 입력
3. 앱: **Gen 불러오기** — 형상 동일성 확인 + 하중·조합 읽기
4. 앱: **불러온 내용 확인(해석 전)** — 모델 차이, 케이스별 하중 형식·합력, 조합 표, 누락 경고, (선택) 앱 자동 하중과 비교
5. 사용자 확인 체크 → 해석(`doc/anal`, 자동 저장 선행)
6. 반력으로 케이스별 하중 합계 확정
7. 설계 검토 → 산출물

## 3. 단계 계획

- **1단계**: 불러오기(형상 동일성 + 하중·조합 읽기) → 확인 화면 → 해석 → 반력 확정 → 부재·접합·사용성(케이스 종류 기준). 내진 특수·ASD 는 전문가 검토. 형상이 바뀌었으면 막음.
- **2단계**: 조합 용도 지정 화면(증폭 지진·중력·ASD, 이름 규칙 자동 추정 + 수정) → 내진 특수 검토 개방, 단면 변경 받아들이기, 최적화·NG 보완을 '단면만 바꾸기' 방식으로.
- 보류: 부재 추가·삭제 모델 받아들이기, 3D 하중 화살표 표시.

## 4. 기술 메모

- 형상 동일성은 기존 `assertGenSync`(13 DB) 에서 하중 DB(`STLD`·`BODF`·`BMLD`·`CNLD`·`LCOM-GEN`)를 빼고 형상 DB 만 비교.
- `LoadInfo` 에 의존하는 설계 코드(`comboKind`·`wind.variants`·`seismic`·`omega`) 는 엔지니어 하중일 때 대체값 필요 — 모든 조합 `basic`, 풍 변형·지진 계수 없음 → 해당 검토는 전문가 검토 이슈.
- 결과 지문·재사용(`reusableResults`) 은 그대로 사용 가능.
- 계산서 PDF 글꼴 축소본에 새 문구 글자 확인(verify-pdf).

## 5. 1단계 구현 메모 (2026-10-26)

- 읽기: 형상 DB(`SYNC_DBS` − 하중 5개) 동일성 → `STLD·BODF·BMLD·CNLD·LCOM-GEN` + 합산 못 하는 표(`FBLA·PRES·PNLA·SWIND·SSEIS·SDSP·ETMP·GTMP·BTMP·STMP·PSLT·MVLD·SPLC`) 존재 여부. 없는 표 GET 은 Gen 이 오류 없이 빈 응답(라이브).
- 합력: 전역 방향 보 하중(UNILOAD 구간 적분 — D 가 모두 ≤ 1 이면 상대 위치, 투영 지원·CONLOAD)·절점 하중은 정확, 자중은 앱 단면적 × γ(+ RC 받침) 추정, 국부 방향·면·압력 하중이 섞이면 ≈. 실제 값은 해석 후 케이스별 반력(화면 표에 반력 −ΣFZ 열).
- 조합 이상: 없는 케이스·중복 이름·빈 조합·정적 아님(ANAL ≠ ST)은 확정 불가, 계수 0 은 경고만. 안내: 자중 외 하중 없음·W/E/L 케이스 없음·조합 없음·조합에 안 쓰인 케이스.
- 확정 후 `Built.genLoads`·`info.gen`: 조합 용도 전부 basic, 풍 변위각 = W 종류 케이스 각각(방향 = 수평 합력이 큰 축 — 앱 자동 하중의 2.12 조합(0.841W_D + 0.7(W_L ± W_T)) 대신 케이스 단독), 지붕 처짐 = L·LR 종류 케이스, 지진 변위각(2.16.1)·내진 13장·ASD·기초 예비검토는 하지 않고 scope warn `genLoads`(전문가 검토). 최적화·NG 보완은 `flow_gen_loads_opt` 로 막음(doc/new 가 엔지니어 하중을 지움). `sent` 의 하중 표 = 읽은 내용 → 이후 Gen 에서 또 바뀌면 해석 전 동일성 검사가 잡음.
- 범위: TW 만(`rb_code`), 추가 구조 모델 제외(`rb_additions`). CN·KR 은 사용성 검토가 앱 케이스 이름에 묶여 있어 후속.
- 회귀 `verify-genloads.ts`(28). 라이브 `live-genloads.ts`(2026-10-26, live-guarded): 정상 모델링 기준(조합 155) vs 모델 + 자중만 → 같은 하중을 엔지니어처럼 PUT(케이스 21·일반 조합 138) → 불러오기·확정 → 해석·설계 검토 — **부재 410개 강도비 완전 동일(최대 0.8747, |Δ| 0)**, 해석 전 합산 vs 반력 최대 0.016%(자중 추정 681.8 vs Gen 681.7 kN), 풍 변위각 X 0.236 동일·Y 0.050 → 0.051(케이스 단독), 지붕 처짐 0.643 동일, 지진 변위각은 검토 안 함, API 오류 0, 원본 12 DB 복원 일치.
