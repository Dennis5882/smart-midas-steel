# Smart MIDAS Steel

MIDAS Gen과 연동되는 강구조물(Steel Structure) 자동 모델링 도구.

## 1. 개요

- **목적**: MIDAS Gen 고객사에게 제공하는 강구조물 모델링 지원 제품
- **연동 대상**: MIDAS Gen
- **연동 방식**: MIDAS Civil/Gen API (MAPI)
- **실행 형태**: 웹 애플리케이션

> 참고: MAPI는 통상 로컬 PC에서 실행 중인 MIDAS Gen 프로세스를 제어하는 방식(OLE/COM 기반)이라, 순수 웹 서비스로 서버가 원격에서 직접 MAPI를 호출하기는 어려움. 웹 UI + 사용자 PC(로컬 실행 파일/에이전트)가 MAPI를 호출하는 하이브리드 구조가 될 가능성이 높음 — 아키텍처 설계 단계에서 확정 필요.

## 2. 주요 기능 범위

1. **부재(기둥/보) 자동 생성**
   - 격자/층 정보를 입력받아 강구조 부재를 자동 배치·생성
2. **접합부(연결) 설계/체크**
   - 접합부 상세 설계 및 검토
3. **단면/재질 라이브러리 관리**
   - 강재 단면 및 재질 속성 관리
4. **해석 결과 후처리/보고서**
   - MIDAS Gen 해석 결과를 받아 보고서·검토 자료 생성

## 3. 개발 환경

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 타입체크 + 빌드
```

- 스택: Vite + TypeScript + React + Tailwind v4 + shadcn/ui (참고: story 프로젝트)
- 브라우저가 로컬 MIDAS Gen의 MAPI를 `midas-nx` SDK로 직접 호출

## 4. 사용 대상

- 고객사 / 외부 제공용 제품 (MIDAS Gen 사용자)
